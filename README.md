# Ryan Maxam | Data Science & Machine Learning Portfolio

Welcome! I'm Ryan Maxam, a data science graduate student with professional experience in pricing and analytics. I use Python, SQL, statistical analysis, and machine learning to explore data, solve problems, and communicate findings.

This portfolio brings together **10 projects** spanning predictive modeling, generative AI, recommendation systems, deep learning, data analysis, and visualization. Each project folder contains its own documentation and available supporting files.

## Featured Projects

### 🏠 [Housing Price Prediction](Housing-Price-Prediction/)
**Predictive analytics · Regression · scikit-learn**

Compared linear regression, decision tree, and random forest models to estimate housing prices from property characteristics. The original notebook run reported **R² ≈ 0.944** for linear regression; see the project README for evaluation details and reproducibility notes.

[Explore the project →](Housing-Price-Prediction/README.md)

### 🤖 [GPT-2 Fine-Tuning with LoRA](GPT2-LoRA-Fine-Tuning/)
**Generative AI · NLP · Transformers · PyTorch · PEFT**

Experimented with parameter-efficient fine-tuning of GPT-2 to generate tags for quotations, comparing baseline and fine-tuned outputs. Includes recorded training results, qualitative examples, and a discussion of model limitations.

[Explore the project →](GPT2-LoRA-Fine-Tuning/README.md)

### 🎬 [Movie Recommendation System](Movie-Recommendation-System/)
**Recommendation systems · Collaborative filtering · Cosine similarity**

Built an item-based collaborative filtering workflow using MovieLens ratings to identify movies with similar user-rating patterns. The project documents the method, dataset, and limitations of similarity-based recommendations.

[Explore the project →](Movie-Recommendation-System/README.md)
