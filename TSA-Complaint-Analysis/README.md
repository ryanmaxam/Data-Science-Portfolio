# TSA Airport Complaint Analysis and Operational Insights

## Overview
Integrate airport complaint data, build six visualizations, and develop operational recommendations.

## Tools
Python, pandas, Matplotlib, Seaborn, Plotly

## Files
- `TSA_Complaint_Analysis.ipynb`
- `data/Airport_IATA_ICAO_Lookup.xlsx`
- `data/Complaints_By_Airport.xlsx`
- `data/Complaints_By_Category.xlsx`
- `data/Complaints_By_Subcategory.xlsx`

## How to use
1. Install packages with `pip install -r requirements.txt`.
2. Open `TSA_Complaint_Analysis.ipynb` from this project directory in Jupyter.
3. Run cells from top to bottom. The notebook uses relative paths to files in `data/` where applicable.
4. Review the displayed charts, tables, and metrics.

## Notes and limitations
The original notebook has inconsistent totals across its validation and summary sections. Reconcile the totals before quoting a single overall complaint figure; counts are not adjusted for passenger throughput.
