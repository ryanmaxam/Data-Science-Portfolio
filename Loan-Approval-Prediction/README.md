# Loan Approval Prediction Using Machine Learning

## Overview
Compare K-nearest neighbors, logistic regression and random forest classifiers on loan approval data.

## Tools
Python, pandas, scikit-learn

## Files
- `Loan_Approval_Prediction.ipynb`
- `data/Loan_Approval_Dataset.xlsx`

## How to use
1. Install packages with `pip install -r requirements.txt`.
2. Open `Loan_Approval_Prediction.ipynb` from this project directory in Jupyter.
3. Run cells from top to bottom. The notebook uses relative paths to files in `data/` where applicable.
4. Review the displayed charts, tables, and metrics.

## Notes and limitations
The original notebook encodes some numeric fields as categories, producing a high-dimensional feature set. Revisit preprocessing, fairness, and performance before treating results as decision-ready.
