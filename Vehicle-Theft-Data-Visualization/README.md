# Kia and Hyundai Vehicle Theft Analysis and Visualization

## Overview
Explore vehicle-theft patterns using four datasets and explanatory visualizations.

## Tools
Python, pandas, Matplotlib, Plotly

## Files
- `Vehicle_Theft_Analysis.ipynb`
- `data/Car_Thefts_Map.xlsx`
- `data/Kia_Hyundai_City_Thefts.xlsx`
- `data/Milwaukee_Vehicle_Thefts.xlsx`
- `data/VICE_Vehicle_Theft_Data.xlsx`

## How to use
1. Install packages with `pip install -r requirements.txt`.
2. Open `Vehicle_Theft_Analysis.ipynb` from this project directory in Jupyter.
3. Run cells from top to bottom. The notebook uses relative paths to files in `data/` where applicable.
4. Review the displayed charts, tables, and metrics.

## Notes and limitations
Counts reflect the source datasets and should not be interpreted as population-adjusted risk.
