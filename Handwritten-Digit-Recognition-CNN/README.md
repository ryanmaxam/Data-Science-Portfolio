# Handwritten Digit Recognition with Convolutional Neural Networks

## Overview
Train and evaluate a convolutional neural network on the MNIST handwritten digit dataset.

## Tools
Python, TensorFlow/Keras, scikit-learn, Matplotlib

## Files
- `Handwritten_Digit_Recognition.ipynb`

## How to use
1. Install packages with `pip install -r requirements.txt`.
2. Open `Handwritten_Digit_Recognition.ipynb` from this project directory in Jupyter.
3. Run cells from top to bottom. The notebook uses relative paths to files in `data/` where applicable.
4. Review the displayed charts, tables, and metrics.

## Notes and limitations
The original executed notebook reports 96.66% test accuracy after two epochs; its original prose conclusion cited a conflicting value. That conclusion has been corrected. The model trains on a 10,000-image subset of the available training set.
