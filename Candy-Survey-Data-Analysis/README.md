# Candy Preference Survey Analysis

## Overview
Clean and reshape the 2017 candy preference survey and examine demographic patterns.

## Tools
Python, pandas, NumPy, Jupyter Notebook

## Files
- `Candy_Survey_Analysis.ipynb`
- `data/Candy_Survey_2017.xlsx`

## How to use
1. Install packages with `pip install -r requirements.txt`.
2. Open `Candy_Survey_Analysis.ipynb` from this project directory in Jupyter.
3. Run cells from top to bottom. The notebook uses relative paths to files in `data/` where applicable.
4. Review the displayed charts, tables, and metrics.

## Notes and limitations
Missing responses, filtering decisions and survey representativeness should be considered when interpreting the results.
