# Lottery Number Analysis and Statistical Visualization

## Overview
Compare historical Mega Millions, Powerball and Pick 10 draws using statistical tests and visualizations.

## Tools
Power BI, statistical hypothesis testing, Excel

## Files
- `Lottery_Statistical_Analysis_Report.pdf`
- `data/Mega_Millions_Winning_Numbers.xlsx`
- `data/Pick_10_Winning_Numbers.xlsx`
- `data/Powerball_Winning_Numbers.xlsx`

## How to use
1. Open the PDF report to review the findings and visualizations.
2. The original Excel source files are provided in `data/`.
3. The underlying Power BI project and test scripts were not included in the uploaded materials.

## Notes and limitations
The supplied materials include the final report and three datasets, but not the original Power BI .pbix file or analysis scripts. The reported tests have not been independently reproduced. Historical results cannot predict future drawings.
