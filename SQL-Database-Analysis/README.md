# Relational Database Analysis with Python and SQLite

## Overview
Query a relational SQLite database to explore people, pet ownership, and treatment records.

## Tools
Python, SQLite, SQL, Jupyter Notebook

## Files
- `SQL_Database_Analysis.ipynb`
- `data/petsdb.sqlite`

## How to use
1. Install packages with `pip install -r requirements.txt`.
2. Open `SQL_Database_Analysis.ipynb` from this project directory in Jupyter.
3. Run cells from top to bottom. The notebook uses relative paths to files in `data/` where applicable.
4. Review the displayed charts, tables, and metrics.

## Notes and limitations
The notebook connects to a bundled SQLite database. SQL joins, filtering, grouping and aggregations demonstrate relational data analysis.
